# Repository Agent Instructions

Determine the nearest applicable project, package, or subsystem boundary before
making changes.

Follow repository-local instructions, specifications, architecture decisions,
ownership rules, and validation commands. More-specific repository guidance
takes precedence over reusable Aether defaults.

Keep changes scoped and evidence-based. Do not modify unrelated systems,
generated files, credentials, private data, or machine-local state.

Prefer deterministic workflows, explicit configuration, reproducible
environments, and repository-relative paths.

When canonical Aether agents or skills are projected into another repository,
treat that repository's local configuration as authoritative.
