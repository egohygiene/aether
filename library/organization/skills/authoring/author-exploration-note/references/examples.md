# Examples and owner handoff

The fixture set is synthetic. Create produces a draft local note; revise keeps
its identity and adds an authored correction; park has a null next step; a
graduate/link example references a separately owned issue and remains draft.
Duplicate identity blocks collection validation without deleting either file.

A conflicting-decision example labels its alternative as a hypothesis and links
the authoritative decision for reconciliation. Missing local sources report
partial rather than proving the idea. A private variant stays private; admitting
classified private sources to a public note is rejected. Free-form prose still
needs review. Checks cannot infer undisclosed sensitivity or source authenticity.

An unmodified create repeat is unchanged. After an authored revision, rerunning
the original scaffold refuses overwrite. The helper creates no directory, issue,
ADR, ledger, knowledge node or remote artifact. Its result only covers bounded
metadata/local references and new-file behavior, not usefulness or human approval.

## Composition

- [Aether78](https://github.com/egohygiene/aether/issues/78) owns brain-dump triage
  and optional issue promotion; it is not implemented again here.
- [Aether102](https://github.com/egohygiene/aether/issues/102) owns conversation
  onboarding/discussion checkpoints; the note links meaningful context as useful.
- [Aether44](https://github.com/egohygiene/aether/issues/44) owns repository journals,
  which summarize historical activity rather than tentative exploration.
- Canonical ADRs/specifications and domain records retain authority. The note's
  draft status, related link or scaffold check cannot accept or supersede them.

## Separate downstream handoff

Holon may later scaffold this optional authored output from a pinned Aether
package using its normal preview/conflict/upgrade/rollback mechanism. Hygiene
owns any applicability decision and Pace reviewed existing-repository rollout.
No consumer migration or new downstream issue is created by this package.

Mindgarden may index a reviewed, visibility-safe note by stable source/revision
and preserve the original repository as canonical. A future `/garden/` view is a
projection, not a new storage location or ingestion implementation. Mindgarden39
is closed not-planned as observed on 2026-11-15; the historical skeleton proposal
is not an active dependency or adoption approval. Current owner contracts would
need separate selection before actual ingestion. This authoring package remains
useful without Mindgarden or any external model/service.
