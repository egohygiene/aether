# ROADMAP.md

## Purpose

Use this skill to create, refine, or review ROADMAP.md in a way that conforms to
its document specification.

## Workflow

1. Read the relevant upstream architecture documents.
2. Read the matching specification in:

       library/organization/specs/architecture/foundation/

3. Determine the document's owned responsibility.
4. Draft or refine the document without duplicating neighboring concerns.
5. Validate against the acceptance and validation criteria in the spec.

## Output Expectations

The resulting document should:

- respect ownership boundaries
- follow the architecture document standard
- remain conceptually clear
- avoid unnecessary implementation detail
- be suitable for both human and AI use
